# 直播报表字段统一说明

本目录依据 `docs/直播间表格` 中 56 个目标链接对应的飞书源表整理：30 份小时报、26 份主播统计表。优先核对最新月份工作表的表头，并结合代表性公式辨别同名指标。核对日期：2026-10-19。本次没有逐条审计历史业务数据。

## 模板结构

- `统一小时报.xlsx`：161 个字段，覆盖各平台、账户类型和业务产品的指标并集。
- `统一主播统计表.xlsx`：105 个字段，覆盖主播场次表现、人员时长和业务结构。
- 每份文件仅一个工作表，按字段清单纵向展示：表头依次为字段名、字段中文名、字段分类、字段描述，每行对应一个具体字段。没有业务记录或计算公式。
- 同口径的共享字段在两表中使用相同中文名称、英文名与说明。英文名采用 `snake_case`。
- 不合并单元格，保留原字段顺序；分类列以颜色辅助区分，冻结首行表头，支持筛选，长文本自动换行。

这些清单定义全量通用字段，并非每个直播间都必须填写全部字段。实际填报时，平台或产品专属字段不适用则留空，在口径备注中说明；不要用 0 代替缺失或不适用。

## 统一后的记录粒度

小时报按“日期 × 平台 × 直播间 × 实际小时区间 × 主播”记录。小时内换主播时拆分区间；同直播间同一时段多个投放账户，先在相同归因范围内汇总互斥指标，不把业务总量复制给每个账户。

主播统计表按同一主播的连续上播场次记录。跨平台拆开，跨零点按日期拆开。源表按人按月汇总的列需要由场次数据汇总形成，不能将月总复制到每个场次。整班投手、场控、助播工时只分配一次。

金额以元、时长以小时或字段明确注明的秒记录。百分率存小数、展示为百分比；ROI 存倍数。成本与转化率先汇总同口径分子分母再计算；分母为零或缺失时留空。去重人数、平均在线、峰值和平均观看时长不能直接按普通计数求和。

## 主要归并与区分

| 原表名称或情况 | 统一处理 |
| --- | --- |
| 主播／主播名称／主播人员；投手／在投投手；场控／助播 | 归并同岗位字段；运营单列；混合岗位名先确认职责。 |
| 消耗／投流消耗／投放消耗／消费 | 归并总投放消耗；直投、短视频、智擎、明星、混投等保留分项，合计不重复相加。 |
| 展示／曝光次数；点击／点击次数 | 分别归并广告展示量、广告点击量；快手行为数暂单列。 |
| AD转化／账户转化／回传；保险支付 | 保留广告后台转化与保险支付指标，分别区别于业务订单、支付订单、保单。 |
| 总保费／GMV／年化保费 | 只有已确认年化的值才映射年化保费；不默认等于现金到账。 |
| 太平洋月缴／月缴保费 | 代表性公式显示已按年化统计，归入月缴年化保费，不能再次乘 12。 |
| 太平洋实收保费／实收ROI | 原公式为月缴年化保费÷12+年缴保费，改称首期折算保费／ROI，明确并非核验到账值。 |
| 组件点击率／支付率／转化率 | 按实际分子与分母拆成明确命名的指标，不凭名称合并。 |
| ROI／微保ROI／业务ROI／保单CAC | 广告消耗口径与含附加成本口径分开；ROI 与 CAC 的附加成本也分别确认，不统一套用固定小时费率。 |
| 千元互动比／千元互动率 | 按互动次数、互动人数、有效评论分别命名，单位是每千元数量，不是百分比。 |
| T0退保／T0脱退／撤单 | 保留不同字段，待业务确认定义、时间窗及重叠关系。 |
| 众民／尊享、E生保／终身保／E惠保、夫妻／小家庭／全家版、1号／2号链接 | 统一为三组“产品／方案名称、保单数、年化保费”，主播表另有保单占比。分项之和与总额只对账，不重复累计。 |
| 别删／勿动、空白分隔、日总／月总、辅助 COUNT 列 | 不作为业务字段；真实直播时长由实际起止时间和停播情况确定。 |

## 需要业务确认的保留项

以下问题已在相关字段的“字段描述”列中标注，模板不替源业务作假设：

- 微保 T0 脱退与其他表 T0 退保是否同义、时间窗如何定义。
- 无忧全能、就医无忧等“一号保单数”的确切含义；少儿守护“差额”的单位和比较对象。
- 50+ 的年龄边界及统计对象，升级／重疾／意外勾选占比的适用分母。
- 快手行为数是否等同点击；观看量、表单、评论是人数还是次数；60 秒与超过 1 分钟的边界。
- 微保部分原订单提交率使用混合事件的特殊公式，暂以“原表特殊转化率”保留；明确后再映射。
- 个别原“平均在线人数”由进房或观看量除以时间计算，不能直接认定为平均同时在线人数。
- 来源中的断裂引用或异常公式不迁入模板；广告归因窗口、业务统计截止时点和附加成本规则需按实际后台确认。
