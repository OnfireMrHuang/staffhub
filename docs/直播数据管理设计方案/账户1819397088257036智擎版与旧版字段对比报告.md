## 建议落地方式

1. 当前表头继续使用“字段类型、字段英文名、字段中文名、字段数据类型、字段描述”五列，公共标准可命名为“巨量营销直播报表字段标准（智擎版、旧版共用）”。本次仅提出建议，未重命名或改写标准文件。
2. 请求配置分别保留 smart → BASIC_DATA、legacy → STD_BASIC_DATA。全量候选字段和互斥/排序规则按对应账户、主题读取。
3. 后续需要单元、素材起量任务、预估转化或长周期游戏指标时，在版本扩展清单维护，不强行填入另一版本。缺失字段表示“不支持”，不能自动补0。
4. 数据入库保留账户ID、抖音号、巨量版本、data_topic、时间粒度，保证数据来源可追溯。同名转化指标仍区分事件时间与计费时间。
5. 字段值类型和跨主题实际数值是否可汇总，需要单独通过样本报表及业务统计范围验证；本次可确定的是当前字段标准可以复用。
