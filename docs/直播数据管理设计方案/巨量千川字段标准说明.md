# 巨量千川表头字段标准

修订日期：2026-10-21。

依据用户更正后的官方[获取投放账户数据](https://open.oceanengine.com/labels/12/docs/1697466393573376)文档，重新整理《巨量千川表头字段标准.xlsx》。本次替代此前基于“获取今日直播数据”接口的字段清单和口径说明。

接口：`GET https://ad.oceanengine.com/open_api/v1.0/qianchuan/report/advertiser/get/`。

## 范围与数量

- 主表共 **117项字段：21项维度、96项指标**。沿用“字段类型、字段英文名、字段中文名、字段数据类型、字段描述”五列表头。
- 96项指标按正文顺序完整保留，94项为 `float`，2项为 `number`，不因名称为次数或订单数而改写类型。
- 参数页单列10项顶层请求参数、7项 `filtering` 子参数、1项请求头、10项应答结构字段。与主表重合的字段不重复计入117项。
- 21项维度包含原生返回、请求上下文、派生及关联字段，不代表接口原生返回21个分组字段。描述中已标明来源和条件。

## 维度标准

| 分类 | 字段 | 来源与条件 |
| --- | --- | --- |
| 时间 | `stat_datetime` | 原生返回；传入 `time_granularity` 时才返回数据起始时间 |
| 时间 | `stat_time_day` | 日/小时粒度下从 `stat_datetime` 派生；区间汇总时留空 |
| 时间 | `stat_time_hour` | 仅小时粒度下派生；日粒度和区间汇总时留空 |
| 时间 | `start_date`、`end_date`、`time_granularity` | 查询日期及粒度，不是实际开播/下播时间 |
| 账户 | `advertiser_id` | 请求参数，也是 `data.list[]` 原生返回字段；长ID建议字符串保存 |
| 账户 | `account_name`、`account_type` | 从账户主数据/试点账户清单按生效时间关联 |
| 账户 | `stat_platform` | 统一术语“统计平台”，本表取值为“巨量千川” |
| 筛选 | `marketing_goal`、`order_platform`、`marketing_scene`、`smart_bid_type`、`status`、`aweme_ids`、`campaign_scene` | 来自 `filtering` 同名子参数，表示查询范围，不是响应分组维度 |
| 直播间关联 | `aweme_id` | 仅 `filtering.aweme_ids` 恰有一个有效ID时回填；无筛选或多ID时留空 |
| 直播间关联 | `aweme_show_id`、`aweme_nick_name`、`room_name` | 单一抖音号归属明确时关联手机端抖音号、昵称及业务直播间名称 |

关联需核对账户、抖音号及生效时间，缺失或歧义时留空。手机端抖音号、接口抖音号ID、业务直播间名称与直播场次 `room_id` 不可混用。

## 时间与查询口径

- `start_date` 不得早于今日前180天，日期格式为 `YYYY-MM-DD`。
- 不传 `time_granularity`：查询区间汇总，跨度不超过180天；不得将区间汇总重复填到每天。
- `TIME_GRANULARITY_DAILY`：按天返回，跨度不超过30天。
- `TIME_GRANULARITY_HOURLY`：按小时返回，跨度不超过7天。
- `stat_datetime` 格式为 `yyyy-MM-dd HH:mm:ss`；本接口没有月粒度枚举。

## 筛选与指标口径

1. 文档明确：账户报表**不再返回 `marketing_goal`**。它仍是 `filtering` 的必填子参数，取值 `ALL`、`VIDEO_PROM_GOODS`、`LIVE_PROM_GOODS`；标准表从请求回填。
2. `order_platform` 是下单平台，取值 `ALL`、`QIANCHUAN`（默认）、`ECP_AWEME`，不能与统计平台 `stat_platform` 混用。
3. 小店随心推不支持 `marketing_scene`、`smart_bid_type`、`status`、`campaign_scene`；搜索不支持 `smart_bid_type`。完整枚举见参数页。
4. `aweme_ids` 是筛选集合，响应不按抖音号分组。多抖音号查询结果不能拆分或复制为各直播间数据；需要单直播间数据时，应按单一抖音号查询并核对归属。
5. 保存筛选条件及文档明确的默认值；未说明默认值的参数保留未传事实，不擅造 `ALL` 等枚举。
6. 新文档未明确金额单位、百分率返回缩放或各比率公式，不沿用旧接口“千分之一分/除以100000”规则，也不沿用自然＋营销全流量口径。
7. 保留直接、间接、7日/14日、计费时间等原文区别，不因名称近似就合并或重复累加。

## 下线标记与核验

`convert_cnt`、`convert_cost`、`convert_rate` 在正文中标记“即将下线”，仍保留在完整目录并注明状态。`ecp_*`、`attribution_*` 按原文分别保留，不未经确认就建立等价替换关系。
