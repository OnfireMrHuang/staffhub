# 巨量千川表头字段标准

整理日期：2026-10-21。

根据官方[获取今日直播数据](https://open.oceanengine.com/labels/12/docs/1763406675800128?origin=left_nav)文档整理，配套文件为《巨量千川表头字段标准.xlsx》。沿用智擎版的五列表头：字段类型、字段英文名、字段中文名、字段数据类型、字段描述。

## 范围与数量

- 标准表头共51项：12项维度、39项业务指标。业务指标按原文顺序保留，未筛减。
- 请求参数：6项；请求头：1项；应答结构字段：4项，单独列示。
- 此标准只覆盖 `GET /open_api/v1.0/qianchuan/report/live/get/`，不是千川全部报表接口的字段全集。
- 标准表头包含请求上下文及主数据关联维度，不局限于接口直接返回的指标。正文没有返回小时明细或直播场次ID，不将日汇总伪装为小时或单场数据。

## 纳入主表的维度

| 分类 | 字段 | 来源 |
| --- | --- | --- |
| 时间 | `stat_time_day` | 从请求 `start_time` 派生统计日期，YYYY-MM-DD |
| 时间 | `start_time`、`end_time` | 请求查询范围，不是实际开播/下播时间 |
| 账户 | `advertiser_id` | 请求参数，长ID建议以字符串保存 |
| 账户 | `account_name`、`account_type`、`stat_platform` | 账户主数据/试点账户清单；统计平台统一为 stat_platform，原清单 version 映射至此 |
| 账户 | `stats_authority` | 请求参数，未传时保存默认值 CURRENT |
| 直播间 | `aweme_id` | 千川请求所用内部抖音号ID |
| 直播间 | `aweme_show_id` | 手机端可见抖音号，通过授权抖音号列表或核验后的映射关联 |
| 直播间 | `aweme_nick_name` | 主数据中的抖音昵称，统一字段名，不冒充本接口返回字段 |
| 直播间 | `room_name` | 试点账户清单中的业务直播间名称 |

账户名称、账户类型及业务直播间归属参考《第一期试点直播间产品 .xlsx》及 `tools/data_report_tool/examples/pilot_accounts.json`。关联应考虑账户、抖音号及生效时间；无法唯一匹配时保留缺失，不把一份总量复制到多个直播间。

`aweme_id`、`aweme_show_id`、业务直播间名称与直播场次 `room_id` 是不同概念。此接口不返回场次ID，不新增虚构的场次标识。`stats_authority=QUALIFICATION` 表示同主体汇总，不得按单账户数据重复累加。

## 关键口径

1. 统计覆盖自然和营销流量，保留原文中整体、营销等口径区别。
2. 文档按开播时间筛选直播间，结束时间要求为开始时间同一天的23:59:59，查询一天0点至24点的数据。
3. `data` 的说明明确金额相关指标单位为“千分之一分”。金额转换为元时除以100000，不能对所有数值统一换算。音浪收入不能直接当作人民币金额。
4. 文档没有明确各比率的分子、分母及返回值是否已乘100，也没有给出GPM计算公式，因此不补写推测公式。
5. 整体ROI、整体下单率、整体成单率仅支持直客客户的官方/自运营抖音号。`stats_authority` 默认 `CURRENT`，`QUALIFICATION` 仅直客账户支持。
6. 客户ID、抖音号ID、查询起止时间及投放账户查询范围已作为维度纳入主表。它们随结果保存，但不代表接口直接返回这些维度。

## 官方文档差异

已交叉核对官方页面正文、[官方Markdown](https://open.oceanengine.com/skiff/api/doc/client/markdown/get/?language=CHINESE&doc_id=1763406675800128)与[官方结构化定义](https://open.oceanengine.com/skiff/api/doc/client/schema/markdown/get/?doc_id=1763406675800128)。

- 结构化定义比正文多20项字段，且均未提供描述；已在工作簿“文档差异待核验”中逐项列出，未纳入39项指标标准，不猜测中文名称或业务口径。
- `ecp_convert_cnt`：正文类型为 `number`，结构化定义为 `number / float`。暂按正文保留，待进一步确认。
- `live_prepay_order_count_alias`（整体预售订单数）在正文中标注为 `float`，按原文保留，没有按字段名称擅自更改为整数。

本次为文档梳理，尚未通过账户数据接口验证可用性；差异项需以官方确认或实际授权接口验证结果为准。
