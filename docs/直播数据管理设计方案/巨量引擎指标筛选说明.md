# 巨量引擎指标筛选说明

本次依据同目录《所有直播间数据时报字段标准统一.xlsx》（161项）、《所有直播间数据日报字段标准统一.xlsx》（105项）及《字段统一说明.md》，按统计对象、统计范围、计数单位、事件及时间窗口逐项比较。此处“关联”是字段语义关联，不是基于业务样本计算的统计相关系数。

已更新《巨量营销-智擎版表头字段标准.xlsx》：原350个指标保留35个、删除315个；保留3个时间维度（小时、天、月）及原五列表头，原保留字段的名称/类型/描述均不改写。2026-10-21补入4个账户维度后，标准表头共42项（7项维度、35项指标）。两份旧系统清单未修改。`params.local.report.json` 的指标列表仍为35项。

新增账户维度为 `advertiser_id`（账户ID）、`account_name`（账户名称）、`account_type`（账户类型）、`stat_platform`（统计平台）。账户ID取自请求参数；其余取自账户主数据/《第一期试点直播间产品 .xlsx》及项目试点账户清单，并在字段描述中注明来源。它们是随报表保存的上下文/关联维度，不应直接加入接口的 `dimensions` 数组。账户名称、类型与归属按生效时间关联，长ID建议字符串保存。

## 保留原则

保留旧表直接统计的广告、直播及保险支付指标，以及其必要组成项和强关联的时间归因版本。按本次要求，额外保留以 `deep_convert` 开头的3个深度转化指标，用于测试和验证深度转化数据。其他没有实际历史字段支撑的扩展分析、其他行业指标和仅名称相近的指标删除。Excel维持简表，口径提示集中在本说明。

“强关联、待确认”表示业务对象接近，值得保留核验，不表示能直接替换旧表字段。计费时间与事件发生时间两套指标不相加。表单合计与表单组成项不重复累计。保费成交金额描述为空，未自行推定为年化保费或现金到账。

## 旧表仍需其他来源的数据

- 主播、投手、助播、实际直播时长、直播间与账户归属：来自排班、直播日志或账户配置。表头已补入账户维度，但仍不能仅凭时间及账户自动拆出各直播间/主播的消耗；需明确直播间映射、查询范围及归属生效时间。
- 业务提交/支付订单、保单份数、核保失败、年化口径、家庭单、月缴/年缴、产品分项、自然/付费业务拆分及T0退保/脱退/撤单：需保险/订单业务后台；广告回传不能直接替代业务全量。
- 组件展示量、直播平均观看时长、平均/峰值在线、直播点赞、去重进入/评论/互动人数、有效评论、5秒观看：本次候选表没有定义明确且等价的直接指标。不能用视频播放时长、营销内容点赞、3秒播放或一般观看次数替代，也不从点击率反推原始组件曝光。
- 观看成本、长时观看成本、观看关注/评论率等：可由保留的同范围基础指标计算。含保单、业务保费、工时或附加成本的指标，需要业务数据补齐后计算；人数、峰值、平均时长不能直接相加。
- 本次新增的3个深度转化指标已同步到查询参数，尚未调用接口验证其与当前3个时间维度的组合、账户权限及实际返回数据。
