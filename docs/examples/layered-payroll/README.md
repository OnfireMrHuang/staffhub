# 主播分层薪酬固定示例

本示例使用虚构数据，月份为 2026-10。输入在 `src/payroll-settlement-example.ts`，不依赖业务 store；`expected.json` 是独立手算期望，不从引擎输出生成。3 位主播产生 4 行结算结果，1 位纯投手被排除。

## 一、规则与范围

当前仅存在全局规则和直播间规则。原员工规则已并入全局，删除员工筛选条件；是否签署竞业协议不再决定这些规则的适用范围。

| 范围 | 补贴 | 系数保费候选 | 保底规则 | 加成规则 |
| --- | --- | --- | --- | --- |
| 全局 | 夜班场次×20、早班场次×10、夜班场次×15，求和 | 正常+早班×2（早班场次≥5）；正常+早班×1.5（早班场次≥3）；正常+早班×3（早班场次≥5）；条件不成立系数为1，候选取大 | 总时长×50、夜班时长×200、早班时长×220、总时长×55，金额取大 | 总时长×ROI档位、总时长×排名档位、早班时长×10，金额求和 |
| 直播间 | 0 | 0 | 0 | 正常时长×20，同一规则集绑定一号房与二号房 |

ROI 档位：小于 3 为 20 元/小时，至少 3 为 45 元/小时。排名档位：闭区间 [1,1] 为 10 元/小时，至少 2 为 5 元/小时。所有时薪规则使用系数计算完成后的有效 ROI 和同房主播排名。

直播间规则遵守一房一规则集的配置约束，集合内补贴、时薪、保费系数各至多一条；本示例规则集仅含一条时薪规则。旧式条件系数规则仍作为合法引擎输入用于验证兼容计算；这些条件是保费项目的计算条件，不是员工筛选条件。若在编辑器将其转成 v2 固定系数项目，不能认为条件被等价保留。

## 二、林晓·一号房的完整手算

来源：总时长100、夜班20、早班30、正常50小时；夜班10场、早班10场；消耗10,000；原始总保费24,000，其中夜班4,000、早班10,000、正常10,000。

1. 全局保费候选为 10,000 + 10,000×2 = 30,000、10,000 + 10,000×1.5 = 25,000、10,000 + 10,000×3 = 40,000，取 **40,000**。直播间保费类别为0。
2. 两范围取大得到有效保费40,000。有效 ROI=40,000/10,000=**4**；等其他主播也算完后，一号房排名为林晓1、陈雨2、周宁3。
3. 全局补贴=10×20+10×10+10×15=**450**；直播间补贴为0；总计补贴=**450**。
4. 全局保底=max(100×50,20×200,30×220,100×55)=**6,600**；直播间保底为0；最终保底=**6,600**。
5. 全局加成=100×45+100×10+30×10=**5,800**；直播间加成=50×20=**1,000**；累计加成=**6,800**。
6. 行月薪=max(6,600,6,800)+450=**7,250**。有效保费40,000只参与前面的ROI与时薪，不再加到工资。

周宁未签署竞业协议，现在也应用原员工规则并入的全局规则：补贴为5×20+2×10+5×15=195；保底=max(80×50,20×200,10×220,80×55)=4,400；累计加成=80×20+80×5+10×10+50×20=3,100；月薪=max(4,400,3,100)+195=4,595。早班2场未触发系数条件，有效保费仍为24,000+4,000=28,000。

## 四、示例覆盖点

- 林晓一号房由累计加成6,800决定工资，其他三行由最终保底决定。
- 林晓总时长保底中的50元/小时低于夜班200元/小时，但100×50大于20×200，验证先乘时长再比较金额。
- 林晓一号房从原始ROI 2.4/第3名升至有效ROI 4/第1名，两个时薪档位均改变。
- 未签约的周宁仍参与全部全局规则，证明员工条件已取消。
- 林晓二号房的系数条件都未触发，但仍存在保费候选9,000，不触发「没有系数规则时沿用原始10,000」的回退。
- 直播间规则集同时绑定两房，按每行正常时长分别产生1,000、1,000、600、600，不合并时长。
- 陈雨 `roles=['主播','场控']` 只结算一次。吴策 `roles=['投手']` 不进入工资与主播排名。
- 原始ROI、排名保留在33列统计里；有效ROI与排名只在核算副本和明细中展示。新结果表为33列统计、全局4列、直播间4列、结果3列，共44列；历史员工范围结果保留原列以便追溯。

完整公式、异常、舍入和归档要求见 `docs/superpowers/specs/2026-10-16-layered-payroll-settlement.md`。
