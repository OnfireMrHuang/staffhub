# 薪酬任务复核与手动归档实施计划

> **For agentic workers:** Use superpowers:subagent-driven-development to implement the assigned units. Preserve concurrent edits; do not commit automatically.

**Goal:** 将员工规则并入全局规则并取消员工筛选条件，以月份组织核算任务，通过页内详情完成计算、结果修正及 HR 手动归档。

**Architecture:** 保留已发布规则任务作为输入快照，列表按月份聚合。Batch 保存核算结果及独立复核覆盖层；核算成功不再修改 archivedMonths，HR 归档动作独立锁定。旧归档与历史规则不原地改写。

**Tech Stack:** React、Vite、Radix UI、Zustand、TypeScript。

**Spec:** `docs/superpowers/specs/2026-10-16-payroll-review-workflow.md`。

## Global Constraints

- 保留全局、直播间两个规则入口；全局适用全部员工、取消员工条件。
- 列表仅筛选栏和只读摘要；点击进入当前页详情，可返回列表。
- 结果分月度核算明细、员工月薪汇总两页签；仅明细支持编辑及追加文本、数字或金额列。
- 直接编辑明细数值，不自动重算计算字段；明确“应用”后按员工汇总明细总计月薪。关联身份只读。
- 计算需弹框确认；归档由 HR 权限执行，管理员在 DEMO 中具备该权限。
- 数据未归档可复核，已归档拒绝重算及修改；保留修改理由与版本。
- 不清空现有业务数据，不提交或推送。

## Review Focus

- 旧员工规则转为无条件全局草稿；旧任务与归档金额不变。
- 编辑数值不自动重算其他字段；待应用时汇总不变，应用后汇总一致。
- 仅明细支持修改；追加列不自动参与计薪，汇总只读。
- 核算后的来源或发布任务改变必须阻止直接归档，需重新确认核算。
- 无权限、归档后、过期版本或无效字段提交均不产生部分写入。
