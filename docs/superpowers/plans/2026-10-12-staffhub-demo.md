# 员工工作台 DEMO Implementation Plan

> 按 executing-plans 在当前工作区连续执行；规格已由用户确认，本次请求授权实现 DEMO。

**Goal:** 以中文可交互网页展示员工、运营数据集、薪酬规则与月度薪资的完整业务链路。
**Architecture:** React 页面组件 + Zustand 浏览器本地状态 + 独立可测试的核算函数；不实现后端或真实 SSO/API。
**Tech Stack:** React、TypeScript、Vite、Radix UI、Zustand。
**Spec:** ../specs/2026-10-09-staffhub-phase-one-design.md
**Global Constraints:** 运营工作台仅三分区；模型结构只读；项目集合并后重算比值；目标显式绑定部门；所有源先落表；未取得飞书内容不得标记为实际数据；无外部发布。
**Review Focus:** 项目集聚合、部门过滤、工资锁定发布、实际资料来源与示例区分。

## 文件与接口
- `src/domain.ts`：实体、项目集核算、数据清洗与校验。
- `src/seed.ts`：可替换的示例数据与来源状态。
- `src/store.ts`：本地编辑、数据集版本、规则版本与工资状态。
- `src/components.tsx`：Radix 对话框、标签、通用表格和操作。
- `src/pages/`：员工、运营、规则、薪资、个人与管理页面。
- `src/App.tsx`、`src/styles.css`：布局、导航、汇报导览与响应式样式。
- `src/domain.test.ts`：业务计算与数据异常测试。
